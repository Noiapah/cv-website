Bachelor project · Signicat · ReuseID

Making digital identity feel simple.

Our team built a working online-banking demonstration that shows how a verified digital identity can be reused securely—without making the experience feel complex.

01 · The challenge

Reusable identity involves authentication, permissions, ownership, and several connected services. The solution was to turn that complexity into a credible journey that both technical and non-technical stakeholders could understand.

02 · The experience

We presented ReuseID through a familiar banking interface. The demo connected mobile authentication with protected banking resources, making each step of the identity flow visible and secure.

03 · The engineering

The frontend used Vue 3, TypeScript, Vuex, Vue Router, within a microfrontend architecture. Java, Spring Boot, REST APIs, relational databases, Flyway, and JUnit formed the backend.

04 · Deployment

GitLab CI/CD with automated testing, Docker, Kubernetes, Helm, and Google Cloud took the system from code to a deployed environment. Scrum, code reviews, and stakeholder feedback guided the delivery.

05 · The security lesson

Authenticating a user is only the first step. The system also verifies that the user has necessary permission & authorization to access resources.

06 · The outcome

The result was a full-stack resuable demo for an external client with practical experience delivering a secure product from planning and prototyping through testing and cloud deployment.
